# 개발 점검 항목

아래 항목은 향후 개발을 위한 체크리스트이며 완료된 기능을 나타내지 않는다.

## 초기화

- [ ] FastAPI 앱과 백엔드 의존성 목록을 추가한다.
- [ ] React(Vite) 앱과 프론트엔드 의존성 목록을 추가한다.
- [ ] 실행 방법과 필요한 환경 변수 이름을 문서화한다.

## 기능 개발

- [ ] 아이디어 입력과 유효성 검사를 설계한다.
- [ ] 유사 서비스 탐색 및 분석 방식을 정한다.
- [ ] 비교 리포트의 데이터 구조와 화면을 설계한다.
- [ ] API 입출력과 오류 처리 방식을 정의한다.

## 검증

- [ ] 주요 사용자 흐름과 오류 상황을 검증한다.
- [ ] 분석 결과의 출처와 최신성을 확인할 방법을 마련한다.
- [ ] 비밀값과 로컬 데이터베이스 파일이 커밋되지 않는지 확인한다.

구현에 앞서 세부 설계를 협의하고, 구조와 코딩 규칙은 [개발 가이드](../CLAUDE.md)를 따른다.
