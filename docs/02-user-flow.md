# 사용자 흐름 구상

이 문서는 계획된 흐름을 설명하며, 아래 기능은 아직 구현되지 않았다.

1. 사용자가 창업 아이디어를 자연어로 입력한다.
2. 시스템이 입력 내용과 유사한 기존 서비스를 탐색하고 수집한다.
3. AI가 각 서비스의 비즈니스 모델, 핵심 기능, 수익 구조, 차별점을 분석한다.
4. 사용자가 서비스 간 비교와 인사이트를 리포트로 확인한다.

## 설계 시 확인할 사항

- 아이디어 입력에 필요한 정보와 입력 검증 기준
- 유사 서비스의 검색 범위와 선정 기준
- 분석 결과의 출처, 최신성 및 확인 방법
- 비교 항목의 표시 방식과 결과가 없거나 부족할 때의 처리

구체적인 화면, API 및 분석 방식은 개발 과정에서 결정한다. 프로젝트의 목표와 진행 상태는 [프로젝트 개요](01-project-overview.md)를 참고한다.
