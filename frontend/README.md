# 프론트엔드

React, Vite, TypeScript 기반 웹 클라이언트를 위한 폴더입니다.
현재 앱 초기화 전이며, 아래 구조는 [개발 가이드](../CLAUDE.md)에 정의된 예정 구조입니다.

| 경로 | 역할 |
|------|------|
| `src/components/` | 공용 UI 컴포넌트 |
| `src/pages/` | 페이지 컴포넌트 |
| `src/api/` | 백엔드 API 호출 |
| `src/types/` | 백엔드 응답 등 공용 타입 |

앱 초기화로 `package.json`과 개발 서버 스크립트가 추가된 후
[프로젝트 README](../README.md#시작하기)의 실행 예시를 참고하세요.
개발 서버의 예정 기본 포트는 `5173`입니다.

컴포넌트는 함수형 컴포넌트와 훅으로 작성하고, 파일과 컴포넌트 이름은
`PascalCase`, 훅과 유틸 이름은 `camelCase`를 사용합니다.
설치된 의존성(`node_modules/`)과 빌드 결과물(`dist/`)은 커밋하지 않습니다.
